# Security

Latch is a governance reference implementation, not a production security boundary.

Please do not rely on its local actor identifiers, authority references, or hash chain as authentication, authorisation, non-repudiation, or tamper-proof custody. Those are deliberately outside the current scope.

If you find a bug that causes Latch to admit reliance outside the active adoption scope, continue reliance while a judgement is contested, accept model self-adoption, or validate a tampered event chain, please report it privately before public disclosure.
