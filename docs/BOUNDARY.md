# Boundary note

Latch separates four things that are often collapsed in AI-assisted work:

1. **Generation** — a model produces a candidate judgement.
2. **Adoption** — an authorised actor explicitly takes responsibility for using that judgement within a defined scope.
3. **Reliance** — a downstream process uses the adopted judgement for a concrete purpose or action.
4. **Challenge** — new information suspends further reliance until every open challenge to the judgement is resolved. A review may explicitly reaffirm the adopted judgement or withdraw it.

The point is not that human adoption is automatically correct. It is that operational authority should be attributable, scoped, challengeable and inspectable.

Latch deliberately does not model legal liability, regulatory approval, model quality, authentication, identity proofing, distributed consensus, or production access control.
